# AnkleBreaker MCP For Unity

Free Unity Editor asset that installs, documents and keeps up to date the
[AnkleBreaker Unity MCP plugin](https://github.com/AnkleBreaker-Studio/unity-mcp-plugin) — the
open-source bridge that lets MCP-compatible AI assistants (Claude, Cursor, Codex, Kimi…) read and
drive the Unity Editor.

Everything you need ships inside the editor, including the Documentation page **Installation**
(requirements, and installing the plugin by hand with or without Git). This file only points you at it.

## Start here

Select **CLICKME** at the root of `Assets/AB/MCPForUnity/` and follow its Inspector. That is the
whole entry point. Until the plugin is installed it offers one button, **Open the plugin setup**.
Once the plugin is there it becomes the hub: plugin and bridge status, the plugin setup, the
dashboard, the documentation and the Welcome below.

## Welcome

`Tools > AnkleBreaker > Unity MCP > Welcome`

Ships with the MCP plugin (2.40.0 and later), so it appears once the plugin is installed and opens
once per project: getting started, more AnkleBreaker assets and studio news.

## Setup — the plugin setup window

`Tools > AnkleBreaker > Dependencies Installer > MCP For Unity`

Or select **CLICKME** and press **Open the plugin setup**. It also opens on its own while the plugin is
missing. It reports what is installed, installs or updates the plugin in one click, and walks you
through the setup steps — checking each one rather than asking you to trust it.

## Everything else — the Documentation window

`Tools > AnkleBreaker > MCP For Unity > Documentation`

The full manual, in-editor: quick start, guided tour, connecting your AI client, updates and version
pinning, running several editors at once, the scripting API, troubleshooting and FAQ. Search covers
every tab, and the links perform the thing they describe instead of just naming it.

## For AI agents

`SKILL.md` at the package root tells a coding agent what this asset does, where things are and
how to check the setup.
